This is the mod for the Official TNTMaster Server. It's not really meant for anyone else but hey if you wanna download it go on ahead

Requirements:
Minecraft 1.20.1
Forge 47.4.10
Java 17

Installation:
Install Curseforge
Plop it in your mods folder
Launch game
